# おすすめ理由の見直し：47地点比較

作成日：2026-11-05。本番には未適用。候補なしの地点の表示方針は未決定。

## 比較条件

現行公開データと同じ県外在住者11,188件・同じ地点別nを確認。地点の選択肢が存在する期間だけを分母にする。基準の「全体」にはその地点を選んだ回答も含む。

- 地点回答30件以上、目的回答10件以上、選択率10%以上。
- 同期間の全体より5ポイント以上高く、かつ1.2倍以上。
- 通過した候補を `（地点選択率－全体選択率）× n/(n+30)` の大きい順に選択。同点は目的件数、目的名の順。
- 数値は編集上の暫定基準。統計的有意差を判定したものではない。
- この補正係数は同じ地点内で共通なので、その地点内の候補順位は未補正の差と同じ。件数条件による除外が少数回答対策の中心。
- 軸に採用した個別目的だけを候補にする。判別不能な結合選択肢は従来どおり除外。
- 訪問・訪問予定の選択者による旅行全体の目的。地点で実際に行った活動の証明ではない。
- 現行理由は47地点すべて食事目的。文章案は比較用で、最終文言ではない。

## 確認したい点

今回の暫定基準では47地点すべてに候補があるため、候補なしの表示方針を決める必要は生じていない。将来のデータ更新時の方針は保留。

地点の内容と結び付きやすい例：春の四重奏→自然鑑賞、宇奈月温泉→温泉、能作→工場見学・体験。

現場確認を要する例：黒部峡谷鉄道→温泉、海の駅蜃気楼・環水公園→文化施設、ファミリーパーク→食事。周遊先や旅行全体の目的の影響という解釈は可能だが、この集計だけで因果関係は確定できない。

全体との差を使っても、実際にその地点でできる活動を自動判定することはできない。文章を「この場所で○○できる」に置き換えない。
